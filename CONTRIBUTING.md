# Contributing

Thanks for helping improve WallpaperFlow Pro.

- **Bugs and ideas:** open an issue using the templates, and include the diagnostics from the About page.
- **Code:** fork the repository, create a branch and open a pull request against `main`. The CI build and tests must pass.
- **Building:** see [docs/BUILD.md](docs/BUILD.md). On Windows, `Build-Exe.cmd` does everything.
- **Licence:** by contributing you agree that your contribution is licensed under GPL-3.0, like the rest of the project.
- **Security issues:** don't open a public issue. Use GitHub's private reporting (Security tab → Report a vulnerability).
